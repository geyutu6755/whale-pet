# 音效素材来源与许可

桌宠所有音效都是**语音素材**（她真的会出声说话），由 `pet/import_sound_pack.py`
从「鲸鱼娘音效包」导入并处理为统一的 22.05kHz / 16bit / 单声道 WAV。

## short/ —— 28 条短反应音

- 生成：Microsoft Edge TTS（edge-tts），音色 `zh-CN-XiaoyiNeural`，语速 +8%、音高 +22Hz
- 性质：**合成女声**，不是官方鲸鱼娘配音，也不是真人情绪表演
- 内容：嗷呜 / 哎呀 / 别别戳啦 / 好耶 / 呜呼 / 摸摸头 / 贴贴 / 小鱼干 / 搞定啦 / 晚安呀 …
- 用于：点击、连戳、抚摸、拖拽、投喂、玩耍、睡醒等本地互动，以及在 Agent 自带台词时
  当作短反应音（避免整句语音盖过 Agent 要说的话）

## voice/ —— 49 条整句语音

- 来源：[aceice01/dsh-whale-pet](https://github.com/aceice01/dsh-whale-pet) 的 `lib/audio.json`
- 许可：**非商业**（个人学习/研究/娱乐使用；非商业性修改、复制、分发需保留许可与致谢；
  禁止商业用途）——完整许可见 `LICENSE-community-dsh-whale-pet.txt`
- 注意：该仓库 README 对二次分发的表述比 LICENSE 更严格，**对外发布前建议先向原作者确认**。
  若你的仓库要求干净的授权链，直接**删掉 `voice/` 目录**即可：桌宠会自动跳过缺失候选，
  退化为只用 `short/` 里的 28 条短音效，功能不受影响
- 用于：任务完成庆祝、出错安慰、思考/工作陪伴、等待批准、打招呼、偶尔的待机撒娇闲聊

## 处理方式

原始素材为 44.1kHz、每条尾部带 1 秒以上静音。导入时统一做了：

1. 裁掉首尾静音（保留自然的头尾留白）
2. 44.1kHz → 22.05kHz（63 抽头窗函数 sinc 抗混叠 + 2 倍抽取）
3. 去直流 + 5ms 淡入淡出 + 峰值归一化到 0.72

重新导入：`python import_sound_pack.py "<音效包目录或 zip>"`
